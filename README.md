# AI Article Writer — LangChain

Учебный проект для задания по созданию цепочки из 5 этапов.

## Задача

Ввести тему и требования к статье → проанализировать задание → разработать план → написать статью → провести редакторскую проверку.

## Цепочка

0. **Приём задания** — интерактивный ввод темы, аудитории, стиля и ограничений.
1. **Анализ задания** — цель, аудитория, стиль, вопросы и критерии качества.
2. **Разработка плана** — заголовок, разделы и основные тезисы.
3. **Написание статьи** — генерация текста по результатам первых трёх этапов.
4. **Редакторское ревью** — оценка, недостатки, фактические риски и рекомендации.

```text
Задание (ввод)
 ↓
Анализ
 ↓
План
 ↓
Статья
 ↓
Ревью
 ↓
Итог
```

## Установка

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

```bash
pip install -r requirements.txt
```

Создайте `.env`:

```env
GEN_API_KEY=ваш_ключ_из_личного_кабинета_gen-api.ru
GEN_API_MODEL=claude-sonnet-4-6
GEN_API_BASE_URL=https://proxy.gen-api.ru/v1
```

> `GEN_API_BASE_URL` — необязательно, уже стоит по умолчанию.  
> Список моделей и их идентификаторов: <https://gen-api.ru> → раздел **OpenAI-формат**

## Запуск

```bash
python main.py
```

Откроется интерактивный ввод задания (этап 0): тема, аудитория, цель, стиль,
объём, обязательные темы и запреты. На любой вопрос можно нажать Enter —
возьмётся значение по умолчанию. В конце показывается собранное задание
и запрашивается подтверждение запуска.

Неинтерактивный режим — через аргументы (см. таблицу выше):

```bash
python main.py --yes --topic "Как малому бизнесу выбрать CRM-систему" \
  --audience "владельцы небольших магазинов" \
  --goal "понять, с чего начать выбор" \
  --length "600-800 слов" \
  --must цена отчётность \
  --avoid "реклама отдельных вендоров"
```

Результаты:
- `output/article.md` — задание, статья и редакторское заключение;
- `output/chain_result.json` — результаты всех пяти этапов, включая введённое задание.

## Почему это цепочка

Результат каждого этапа становится входом следующего:

`brief → analysis → plan → article → review`

Задание, введённое на нулевом этапе, проходит через всю цепочку: анализ
превращает его в критерии качества, план покрывает обязательные темы,
при написании учитываются стиль и объём, а ревью проверяет соответствие
именно тому, что запросил пользователь.

## Расширение

В production-версии между планом и написанием можно добавить Web Search/RAG
для поиска и проверки актуальных источников.
